# GNN-BERT Music Context Understanding

A supervised neural network project for understanding musical context
using BERT and Graph Neural Networks.

## Project

This project implements:

1. BERT-based music text/tag understanding
2. GNN-based music structure understanding
3. GNN-BERT multimodal fusion
4. Contrastive audio-text retrieval

## Course

CSE425: Neural Networks

## Main Technologies

- PyTorch
- PyTorch Geometric
- Hugging Face Transformers
- Librosa
- Scikit-learn

See the repository directories for source code,
